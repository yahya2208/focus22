| Property | Duration | Easing |

| Input fields | 0.15s | `cubic-bezier(0.4, 0, 0.2, 1)` |
| Buttons | 0.2s | `cubic-bezier(0.4, 0, 0.2, 1)` |
| Cards / containers | 0.3s | `cubic-bezier(0.4, 0, 0.2, 1)` |
| Achievement reveals | 0.4s | `cubic-bezier(0.22, 1, 0.36, 1)` |
| Countdown / page transitions | 0.5s | `cubic-bezier(0.22, 1, 0.36, 1)` |
| Bouncy / playful | — | `cubic-bezier(0.34, 1.56, 0.64, 1)` |

**Two easing curves identified**:
- `cubic-bezier(0.4, 0, 0.2, 1)` — standard (Material Design default)
- `cubic-bezier(0.22, 1, 0.36, 1)` — smooth/decelerate
- `cubic-bezier(0.34, 1.56, 0.64, 1)` — bounce/overshoot (rare)
